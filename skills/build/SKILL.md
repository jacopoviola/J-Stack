# Build One Lake
Prerequisite: plan PASS.
Read state, locked contracts, and only needed lake context. If no lake is active, propose the next planned lake and ask one question to activate it. Create SPEC/ACCEPTANCE before code. Search before unfamiliar infrastructure. Implement the complete bounded lake including critical error paths and approved tests. Follow autonomy boundary; HOLD on high-consequence decisions. Never silently change locked contracts. Do not self-review. When complete, summarize behavior/files/tests/unresolved issues/verification commands, set VERIFYING, and stop.
